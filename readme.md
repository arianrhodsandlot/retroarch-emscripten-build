# RetroArch Emscripten build

This repository contains RetroArch builds for emscripten.

Files are all grabbed from [Libretro Buildbot](https://buildbot.libretro.com/stable/), for example, https://buildbot.libretro.com/stable/1.22.2/emscripten/RetroArch.7z, and then extracted without any modification.
